## Projects

### [excel-column-mapper](excel-column-mapper/)

A Tkinter desktop app that copies rows from a source Excel sheet into a chosen
tab of a target workbook, using column mappings you define at runtime. Each
mapping is `source column → target column`, with an optional "extract after
&lt;delimiter&gt;" rule per mapping, an optional auto-incrementing ID, and a live
preview that always shows exactly what will be written.

See its [README](excel-column-mapper/README.md) for setup and usage.
